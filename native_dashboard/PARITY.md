# Qt 与网页版功能对齐

本地 Qt 通过同一侧边栏切换 9 个入口；页面采用原生 Qt/QML，复用现有 HTTP/WebSocket 后端。采集预览保留 NVIDIA 原生视频显示，空间页保留 Qt Quick 3D。没有嵌入网页。

| 网页入口 | Qt 功能 |
| --- | --- |
| Sessions `/` | 任务创建、编辑、进入、结束；当前任务统计、take 的 QC/人工判断与空间回放入口 |
| Spatial review `/3d` | 原生多路预览、模型/轨迹、建图状态、任务与录制控制、准备后回放、暂停/拖动/返回实时 |
| Rosbags `/bags` | 全部/当前目录、时长/大小/消息/话题、完整性/评分/回放状态、完整性检查、空间回放、确认删除 |
| Datasets `/umi-dataset` | 多条录制选择、UMI/LeRobot、任务描述、相机布局、图像尺寸、分段方式、进度和结果 |
| Scoring `/scoring` | 录制/可选话题，先完整性检查再评分，各相机结果与质量指标 |
| Hand pose `/handpose` | WiLoR 依赖检查、启动/停止、进度与日志、保存结果、原生骨架/时间轴/播放、就绪预览视频 |
| Optimization `/optimization` | 相机/图像流/运行名、启动/停止、阶段进度、日志、保存的运行、VIO/COLMAP 交互轨迹 |
| Recorder `/recording` | 默认/分组/逐话题选择、名称、目录浏览/选择、录制启停、存储与完整性状态 |
| Settings `/settings` | 夹爪追踪、手部叠加（后端支持时）、夹爪遮罩、语音音量/试听、确认重启及恢复检查 |

侧边栏分组、编号、顺序和英文入口名称与网页一致；窄窗口收为编号导航，并显示名称提示。默认仍打开原生采集页，启动命令仍为 `./native_dashboard/run.sh`。

切离空间页释放本客户端的实时视频连接并隐藏 NVIDIA 子窗口；已有 MP4 回放暂停并保留时间位置，返回时恢复先前播放/暂停状态。后端录制与处理作业独立继续；页面加载后重新读取状态。仅当前处理页低频轮询进度，不轮询扫描录制库。任务、删除、配置、优化/导出启动在录制期间禁用；录制停止仍可使用。

验证使用独立模拟后端及 Xvfb 显示，覆盖全部入口加载、实际控件操作、请求参数、错误反馈、录制中跨页禁用、删除确认、手部结果及优化轨迹加载。模拟验证不代表实际设备录制、WiLoR 推理、数据集文件生成或重建质量已经验收。真实采集服务保持运行，驻留 Qt 客户端不会被自动重启；客户发布/kiosk 仍需按部署流程更新。
