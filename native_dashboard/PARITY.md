# Qt 桌面功能

本地 Qt 通过同一侧边栏切换 7 个入口；页面采用原生 Qt/QML，复用现有 HTTP/WebSocket 后端。采集预览保留 NVIDIA 原生视频显示，空间页保留 Qt Quick 3D。没有嵌入网页。外观采用与网页一致的暖纸色主题，控件与页面布局说明见 [原生界面主题](UI.md)。

| 本地入口 | 功能 |
| --- | --- |
| Sessions | 任务创建、编辑、进入、结束；当前任务统计、take 的 QC/人工判断与空间回放入口 |
| Spatial review | 原生多路预览、模型/轨迹、建图状态、任务与录制控制、准备后回放、暂停/拖动/返回实时 |
| Rosbags | 全部/当前目录、时长/大小/消息/话题、完整性/评分/回放状态、完整性检查、空间回放、确认删除，以及两端录制回传合包 |
| Scoring | 录制/可选话题，先完整性检查再评分，各相机结果与质量指标 |
| Optimization | 相机/图像流/运行名、启动/停止、阶段进度、日志、保存的运行、VIO/COLMAP 交互轨迹 |
| Recorder | 默认/分组/逐话题选择、名称、目录浏览/选择、录制启停、存储与完整性状态 |
| Settings | 定位图像遮罩、确认重启及恢复检查 |

侧边栏提供分组、编号与入口名称；窄窗口收为编号导航，并显示名称提示。默认仍打开原生采集页，启动命令仍为 `./native_dashboard/run.sh`。

首次访问异步创建页面，后续切换复用控件并保留表单和选择。录制库元数据共用 60 秒缓存，显式刷新、业务修改或录制状态变化使缓存失效；正在扫描时切换目录范围，会在当前请求结束后读取最后选择的范围。仅当前处理页低频轮询进度，不轮询扫描录制库。

切离空间页隐藏 NVIDIA 子窗口，保留本客户端实时视频连接和 H.264 引用解码；隐藏的解码输出丢弃，原始图像跳过显示处理。返回后收到新输出才展示实时视频。空间轨迹增量仍持续接收，隐藏期间暂缓场景通知与轨迹几何更新。已有 MP4 回放暂停并保留时间位置，返回时恢复先前播放/暂停状态。后端录制与处理作业独立继续。任务、删除、配置、优化启动在录制期间禁用；录制停止仍可使用。细节与验证数据见 [界面与切页说明](UI.md)。

验证使用独立模拟后端及 Xvfb 显示，覆盖全部入口加载、实际控件操作、请求参数、错误反馈、录制中跨页禁用、删除确认、优化轨迹加载。模拟验证不代表实际设备录制、重建质量已经验收。真实采集服务保持运行，驻留 Qt 客户端不会被自动重启；客户发布包含原生程序与运行库。

回放缓存仅由用户点击“准备并回放”触发；录制与合包完成不自动准备。UMI/LeRobot 导出、设备手部骨架叠加和夹爪开合追踪已移除；COLMAP 优化保留。
