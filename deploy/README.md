# Insight 安装与升级

停止录制、等待保存完成，关闭 Qt，然后运行：

```bash
bash insight-dashboard-v2.1.1.run /原安装目录
```

`/原安装目录` 是原来存放 `docker-compose.yml` 和 `config/` 的目录。首次安装也使用这条命令，指定要安装的位置即可。

升级自动加载全部镜像、迁移旧配置并启动服务。成功后自动清理旧版镜像和安装包。原配置、标定和录制数据保留。

v2.0.6、v2.0.7、v2.0.8 和 v2.1.0 均直接使用这一个升级包，填写原安装目录即可。

完成后重新打开 Qt，手机网址不变：`http://<Jetson-IP>:8765/mobile`。

升级与录制启动使用本项目 `config/.capture-upgrade.lock` 的进程锁互斥。
升级期间开始录制会返回“系统正在升级”；正在准备、录制或保存时，升级会退出，
保留现有服务。加载镜像后还会再次检查状态，后端运行但无法返回状态时也不会直接停服。
锁随进程退出释放，保留的空文件不表示仍在升级，不要删除或替换它。

历史版本的后端还不支持此锁，首次升级到该版本时仍须保持采集空闲，直到升级命令退出。
镜像加载后的复查可以发现期间已开始的录制，但不能代替历史后端缺少的并发互斥。
`update.sh --force` 仍是明确允许中断录制的维护选项，正常升级不使用。
