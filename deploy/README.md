# Insight 安装与升级

停止录制、等待保存完成，关闭 Qt，然后运行：

```bash
bash insight-dashboard-v2.1.1.run /原安装目录
```

`/原安装目录` 是原来存放 `docker-compose.yml` 和 `config/` 的目录。首次安装也使用这条命令，指定要安装的位置即可。

升级自动加载全部镜像、迁移旧配置并启动服务。成功后自动清理旧版镜像和安装包。原配置、标定和录制数据保留。

v2.0.6、v2.0.7、v2.0.8 和 v2.1.0 均直接使用这一个升级包，填写原安装目录即可。

完成后重新打开 Qt，手机网址不变：`http://<Jetson-IP>:8765/mobile`。
