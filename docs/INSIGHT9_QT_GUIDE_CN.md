# Insight9 电脑 Qt 使用指南

适用：Insight9 头部 + Insight3 A 右腕 + Insight3 B 左腕，配置 `jetson-nx`。

电脑端使用 Jetson 原生 Qt，桌面浏览器前端已移除。按钮名称保留界面英文；手机浏览器操作见《手机采集指南》。

## 1 打开 Qt 并管理任务

在 Jetson 的项目或安装根目录执行 **`./native_dashboard/run.sh`**，打开已安装的 Qt 程序。默认以 30 FPS、全屏运行，顶部应显示 **Connected**。它只启动 Qt；后端未连接时，按《配置与维护说明》排查。

### 先找到你要做的事

| 目的 | 左侧入口 |
| --- | --- |
| 建立任务、查看任务下的 Take | Tasks |
| 看三路画面、地图与轨迹，进行校准 | Spatial |
| 找录制文件、回放、检查完整性、删除 | Recordings |
| 计算和查看轨迹质量分数 | Scoring |
| 运行 COLMAP，比较重建与 VIO 轨迹 | Optimize |
| 选择录制话题和存储目录，起停录制 | Recorder |
| 调整腕部定位遮罩、重启后端 | Settings |

### 新建或选用任务

1. 打开 **Tasks**，点击 **New task**。
2. 填写 **Task ID**（例如 `pick_and_place`）、**Task name**（任务名称）和 **Instructions**（动作说明）。**Capture profile** 通常保留默认的 `dual_arm_umi`，再点击 **Save**。这是任务元数据，不会切换设备配置。
3. 在任务列表中选中要用的任务，点击 **Use task**，核对当前任务和下一条 Take 编号。

编辑说明用 **Edit**。结束任务用 **End task** 并确认，历史数据保留。新建、编辑和任务切换应在空闲时进行。

任务下每一条 Take 会显示保存情况、QC（采集质量检查）摘要、人工判断和异常数量。点击该条的 **Play** 可进入回放。**Passed/Unchecked 是摘要，最终复查仍要阅读异常和完整性详情。**

## 2 选择录制目录并起停录制

手机和 Qt 使用同一个当前任务。由一端负责起停，避免另一端同时切任务、改目录或重置地图。

### 起录前检查

打开 **Spatial**，确认头部、左腕和右腕都有新图像及运动输入；需要公共轨迹时，先按第 3 节校准。打开 **Recorder**，核对当前任务、录制话题与目标目录。

普通采集使用已确认的默认话题方案。Recorder 支持默认、分组和逐话题选择；临时取消话题可能使回放、评分或优化缺少输入。需要试验时另建任务，并保留实际话题清单。

如需换目录，先浏览目标路径，再点击 **Use folder** 才会生效。确认目录属于正确的采集盘；录制和保存期间不能切换目录。录制名可选，任务存储子目录由系统管理。

### 完成一条 Take

1. **开始。** 在 Spatial 点击 **Record**，或使用 Recorder 的起录入口。等待准备完成并确认录制状态后，再执行动作。
2. **观察。** 留意图像、VIO、时钟与存储告警。切换 Qt 页面不会停止录制。
3. **停止。** 点击 **Stop**，等待 **Saving…** 结束。保持供电，不拔盘，不连续点击。
4. **核对。** 查看本条 Take 与输出路径，再到 Recordings 找到录制，按第 4、5 节检查。

**完成标志：收尾结束，本条有明确的已保存记录和输出目录。** 只有起录计时、预览画面或目录出现，都不能代替保存完成。

### 动作做错了怎么办

保存后，在 Spatial 点击 **Reject last take** 并确认，可作废最近一条 Take。原始文件仍保留。**End task** 结束任务，**Reject last take** 作废录次，**Delete** 删除文件，三者用途不同。

关闭 Qt 不会停止后端录制。再次打开后先核对实际状态；保存异常或写入器未结束时，保留原件并处理错误，不要强行开始新录制。

## 3 查看空间状态并建立公共地图

打开 **Spatial**。三路画面用于检查设备输入，三维区域用于查看地图、模型和轨迹。

### 先理解显示的轨迹

每台相机有自己的 VIO 运动估计。只有完成公共地图定位后，头部与双腕的相对位置才可放在同一坐标系中理解。看到 **Local VIO / Unaligned** 时，不要把设备间显示位置当成已校准的相对位置。

### 建图与定位步骤

1. 让三台设备能观察同一片有纹理、光照稳定的环境。
2. 点击 **New map** 并确认。当前公共地图会重建。
3. 缓慢移动头部视角，确认 **Map points** 增加。
4. 让左右腕分别观察头部已建图的环境，等待定位状态更新。
5. 做短距离缓慢运动，核对相对运动是否合理，再开始正式动作。

普通录制允许先开始再校准，以保存校准过程；此时记下校准完成时刻。回放、专用标定录制以及起停和保存转换期间不能重置地图。

“地图匹配/已定位”表示获得公共地图约束；“VIO 推算/仅本地 VIO”没有新的地图匹配；“静止约束”利用静止证据保持位姿。显示平滑不等于实际精度已通过验收。相机或 VIO 重启、换机、佩戴位置改变、长断流后，要重新确认定位。

### 操作三维视图

| 操作或控件 | 作用 |
| --- | --- |
| 左键拖动 / 右键拖动 / 滚轮 | 旋转视角 / 平移 / 缩放 |
| Reset view | 恢复观察视角 |
| Keep trails / Clear trails | 控制轨迹显示保留 / 清除屏幕上的轨迹 |
| New map | 重建公共地图，会改变当前校准状态 |

视角和显示轨迹的调整不修改录制原件。当前旧 **Check** 按钮对应功能不可用；检查设备看输入状态，检查录制文件使用第 5 节的 **Check integrity**。

## 4 找到录制并回放

开始前确认正在录制的 Take 已经保存，后台没有起停或收尾操作。

### 找到正确的文件

1. 打开 **Recordings**。
2. 选择 **All folders** 或 **Current folder** 范围，点击 **Refresh**。
3. 根据路径、录制名、时长、大小、消息数和话题数核对目标。同名录制要用完整路径区分。

### 回放视频和轨迹

1. 对目标录制点击 **Play**。也可以在 Tasks 的 Take 上点击 Play，或在 Spatial 的 Playback 区域选择录制并点击 **Load**。
2. 首次使用时等待视频和位姿时间轴准备完成，准备期间不要重复加载。
3. 用 **Pause / Resume** 暂停或继续，用时间轴跳到指定位置。检查三路视频、轨迹及异常对应时刻。
4. 检查结束后点击 **Live**，回到实时状态，再开始新录制。

切到其他 Qt 页面时，视频回放暂停并保留位置。回放准备由手动 Play/Load 触发，不会自动把所有录制批量转码。

### 如何理解回放结果

视频和位姿按统一时间轴查看，不能因此推断源数据没有丢帧，或三台相机已经硬件曝光同步。缺少位姿时应检查提示和输入话题，不能解释为设备没有移动。缓存失效时可重新准备，空间不足则交维护人员确认可清理的派生文件。

### 删除前先核对备份

Recordings 的 **Delete** 会删除所选原始录制，须核对确认弹窗。正在录制、保存、准备或播放的目标受到操作限制。先完成副本核验，再按保留要求删除；不要把“作废录次”误做成删除原件。

## 5 检查完整性并查看轨迹评分

复查顺序是：**保存成功 → 文件完整性 → 轨迹表现与动作内容**。三项分别判断。

### 第一步 检查录制是否完整

在 **Recordings** 对目标录制点击 **Check integrity**，等待结果。重点看必需话题是否存在、消息数量和时间跨度是否合理，以及图像源时间戳重复、回退和间断。

静态 TF 是坐标变换配置，通常只需确认存在，不能按连续视频帧率判断。总消息多也不能证明所有必需话题完整。检查失败时保留原始文件、错误和异常时刻，先复查原因。

### 第二步 计算轨迹评分

1. 打开 **Scoring**，选择同一条录制。
2. **Trajectory topic (optional)** 通常留空，让系统发现可评分的 VIO 协方差话题；需要指定时填写实际存在的话题。
3. 点击 **Check and score**，等待结果，查看每台相机的分数与异常信息。

**当前 Check and score 在完整性失败后仍可能继续评分。必须分别查看完整性和评分结果，不能以“评分完成”代替完整性通过。**

### 第三步 决定保留还是复查

| 分数 | 界面等级 |
| --- | --- |
| 90 至 100 | Excellent |
| 70 至小于 90 | Good |
| 50 至小于 70 | Fair |
| 小于 50 | Poor |

评分反映协方差及异常段等内部统计。持续异常可能触发封顶；无适用话题、空数据或无效数据应查看错误。高分不代表外部定位精度，也不能覆盖文件缺失和动作不合格。

结合回放、QC 异常时刻和任务动作要求复查。交接时分别记录完整性结果、评分话题与结果、人工判断和原因。

## 6 运行 COLMAP 优化并比较轨迹

COLMAP 根据录制图像进行重建，适合进一步比较轨迹。正式采集期间避免同时运行这类计算任务。

### 启动一次优化

1. 打开 **Optimize**，选择 **Recording**。
2. 选择 **Camera** 和 **Stream**。所选图像流必须有对应相机参数，录制中也要有图像与 VIO 数据。
3. 按需填写 **Run name**，使用便于追溯且不会与重要旧结果冲突的名称。
4. 点击 **Run**，观察阶段、进度和日志。需要中止时点击 **Stop**，等待任务结束。

### 查看结果

完成后，在已保存运行列表中选中对应记录并点击 **Load**。图中 **红色为 VIO 轨迹，绿色为重建轨迹**。

比较有效覆盖范围、尺度、坐标关系以及异常片段。两条线接近不能代替独立精度评估。低纹理、模糊、纯旋转和视角不足，都可能使重建失败或不可靠。

使用 **View log** 查看详细日志。保留录制路径或稳定 ID、运行名、相机、图像流、参数和软件版本，便于重复运行和比较。

### 运行或加载失败

先检查所选录制是否有需要的图像、相机参数和 VIO，再检查空间与日志，修正后重试。不要通过改录制名掩盖输入缺失。

加载失败时，界面可能仍显示上一次成功加载的图和运行名；以当前名称和错误信息为准，不要把旧图当作本次结果。

## 7 修改设置与处理常见问题

### Settings 中的两个操作

**Wrist image mask**：设置腕部图像底部用于定位处理的遮罩比例，范围为 0 到小于 1，模板默认值为 0。修改从后续特征处理生效。它不裁剪原始录制图像，也不用于数据脱敏。

**Restart backend**：确认设备空闲、数据已保存后，再点击并确认重启。等待后端重新连接，复查三路输入、时钟和定位。恢复失败时查看诊断，不要连续点击重启。

### 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 顶部 Disconnected | 检查后端和本机连接；由维护人员处理服务，勿在未知录制状态下反复启动 |
| Record 不可用或提示 Select a task | 在 Tasks 选任务并点 Use task；检查预检错误，确认已退出回放且不在保存 |
| 有图像，但三维位置不合理 | 检查是否 Local VIO / Unaligned，再按第 3 节校准 |
| 菜单或确认框打开时视频暂时消失 | 关闭弹窗后检查恢复；原生视频窗口可能临时隐藏 |
| 保存一直不结束 | 保持原件和供电，记录空间、路径与错误，交维护人员处理收尾 |
| 提示任务或录制已变化 | 另一端可能已操作；刷新并核对当前任务、Take 和路径，再继续 |
| 同名录制没有评分徽标 | 核对路径和结果关联；移动路径或旧报告可能需要对目标重新检查 |
| Qt 缺运行库或无法打开 | 使用匹配的发布产物和 Jetson 媒体运行环境，由维护人员处理 |

### 交接一个故障

点击顶部 **Copy diagnostics** 保存诊断，附上发生时间、任务、Take、输出路径、错误原文和最近操作。收尾失败的暂存目录可能包含唯一原始数据，不要作为缓存删除。
