# 现场采集流程

## 打开控制界面

- 使用 Jetson 本机屏幕时，执行 `./native_dashboard/run.sh` 打开 Qt。
- 使用手机时，连接与 Jetson 可互通的网络，打开 `http://<Jetson IP>:8765/mobile`，无需打开 Qt。

两种界面共用一个后端。检查图像、设备状态、当前任务与录制存储，再开始采集；失败原因显示在界面中。

## 任务与录制

Qt 的 Tasks 页面可新建、编辑、启用和结束任务。Task ID 创建后固定，同一任务的 Take 编号持续递增。手机可选择已有任务。

没有启用任务时不能开始普通采集。录制期间不能切换或编辑任务；停止录制并等待保存完成后可开始下一条。

需要保存完整校准过程时，先开始录制，再点击校准。三台相机看到共同的有纹理场景后，头部开始建图，腕部在匹配成功后进入公共地图坐标系。未定位腕部显示的 Local VIO 轨迹仍属于各自局部坐标系。

元数据保存在：

```text
outputs/results/sessions/<task_id>/
  task.json
  session.json
  takes/take_0001.json
```

原始录制写入当前存储根目录下的 `<task_id>/`。升级保留任务和原始数据，不移动或重命名已录制的包。

## 采集中与保存后

相机、定位和存储异常持续出现时，质量监测将异常写入当前 Take，不自动删除原始录制。设备断开时，其余设备继续显示；重新连接后自动接收恢复的数据。

Insight9 本地录制保存为标准 MCAP。EgoHalo 双端录制先保存两端数据，之后在 Recordings 页面手动合包；保存完成即可开始下一次录制，不必等待合包。

在 Recordings 页面检查完整性、评分或准备回放。回放缓存由用户手动准备。COLMAP 位于 Optimize 页面，可选择包、相机和图像流，查看日志与重建轨迹。
