前端使用手册

本地 Native Qt 与网页版的选择、实时预览、录制、回放、质检和数据处理。

只展示视频流和轨迹：推荐本地 Native Qt Jetson 本机原生硬件解码，预览帧率更高、延迟更低。任务管理、质检、数据集导出和高级处理使用网页版。

软件 2.0.72026-09-20

适用对象：数采员、演示人员、现场管理员和数据工程师

范围：只包含前端操作；不包含安装、镜像构建和代码开发。

场景推荐说明

两套前端共用同一个 Dashboard 后端。切换前端不会改变原始录制格式；关闭前端也不等于停止录制。

使用范围：只在 Jetson 本机运行和查看，不提供任何远程预览方式。

2　启动

2.1　启动命令速查

# 终端 1：源码目录，启动后端和本地网页；必须带 --jetson
DISPLAY=:0 ./scripts/run_dashboard.sh --jetson

# 客户部署包对应命令
DISPLAY=:0 ./run_dashboard.sh --jetson

# 终端 2：需要 Native Qt 时再执行
DISPLAY=:0 ./native_dashboard/run.sh --fps 30 --fullscreen

--jetson 属于 Dashboard 启动脚本；Native Qt 在另一个终端启动，不接收该参数。

健康检查：curl -s http://127.0.0.1:8765/healthz，返回 ok 后再操作。

Native Qt（Jetson 本机）

默认连接本机 127.0.0.1:8765。需要窗口模式时去掉 --fullscreen。

F11 切换全屏；Esc 退出全屏。

网页版

带 --jetson 的命令会自动打开本机全屏网页。

首页：http://127.0.0.1:8765/

视频与轨迹：http://127.0.0.1:8765/3d

停止整个后端：docker compose down。执行前必须确认没有录制或处理任务。关闭 Qt 窗口或浏览器只关闭前端，不会自动停止录制。

Native Qt 最新实现位于 experiment/qt-live-frame-deadlines 分支的 native_dashboard/。现场应使用已安装版本，不要在采集中切换分支或临时构建。

3.1　只看视频和轨迹

  1. 等待顶栏显示“姿态在线”。
  2. 确认三路视频有画面，右上角“输出 FPS”持续更新。
  3. 选择 30 FPS；资源紧张或录制期间不稳时改为 25 FPS。
  4. 确认右侧模型和轨迹随设备移动。
  5. 保持“实时”模式并全屏展示。

短时实机验证中，30 FPS 目标下三路输出约 28.6–29.4 FPS。实际帧率以界面显示为准。

3.3　任务与录制

  1. 从“采集任务”选择任务，点“进入任务”。Qt 不能新建任务，需使用网页 Sessions。
  2. 确认视频、姿态和轨迹正常。
  3. 点“开始录制”；看到红色“录制中”后开始动作。
  4. 完成后点“停止录制”，等待状态回到空闲。
  5. 动作失败时点“作废最近一条”。该操作不删除原始 MCAP。
  6. 需要检测位复核时点“采集检查”。

“新建地图”会清空旧地图。只在重新校准时使用，录制中不可操作。

3.4　回放

选择 rosbag → “刷新”（如需要）→ “载入” → 使用“暂停/继续”和时间轴 → “返回实时”。

Qt 只做快速查看；bag 删除、质检和导出使用网页。

4.1　任务与 Take

Sessions：选择任务并点 Enter task set。New task 创建任务， Edit 修改，End current 退出。未进入任务时，普通录制会被拒绝。作废 Take 不会删除原始数据。

4.2　网页实时与 Recorder

Spatial：Play 回放，Stop 停止，Go live 返回实时； Clear trail 只清显示；New map 会清空旧地图。

Recorder：确认 Task、目录和空间 → Refresh topics → 选择 topics → Start capture → Stop。停止后等待缓存排空和 bag 发布完成。

4.3　Rosbags 与 Scoring

Rosbags 删除不可恢复，必须先备份。Scoring 选择 bag 后点 Run analysis：

  • Complete：topic 丢帧均在阈值内；Incomplete：至少一个 topic 超限；
  • scored 只表示评分已运行，不代表数据完整；0–100 分用于同类录制比较。

4.4　数据处理

  • Datasets：选 bags → 选格式 → 填英文任务指令 → 选布局/切分/分辨率 → Build。质量不合格的源 bag 可能加 fail_ 前缀，但不会删除。
  • Hand pose：选 bag → Extract hand pose → 等待完成 → 播放或拖动时间轴。
  • Optimization：选 bag 和 Insight9 → 启动 COLMAP；运行期间不要录制。
  • Settings：调整音量、遮罩和追踪显示。只有全部空闲时才能 Restart backend。

5　推荐工作流

视频与轨迹展示

后端就绪 → Native Qt → 30 FPS → 检查三路输出 → 全屏。

正式采集

网页建任务 → Qt 进入任务并录制 → 网页 QC/Scoring → 网页导出。

7　操作红线

  • 录制中不要重启后端、相机或整机，不要拔插相机和录制盘；
  • 录制时不要运行 COLMAP、批量导出或手姿提取；
  • 关闭 Qt 或浏览器不等于停止录制，必须先点“停止录制”；
  • 作废不删除数据；Rosbags 删除不可恢复；
  • 停止后等状态完全回到空闲，再开始下一条；
  • _staging/ 是中断恢复区，不要手动清理。
