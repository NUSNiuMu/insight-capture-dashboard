# Insight9 手机采集指南

适用：Insight9 头部 + Insight3 A 右腕 + Insight3 B 左腕，配置 `jetson-nx`。

手机负责现场采集。数据保存在 Jetson 上；手机关闭页面、锁屏或断网，都不会替你停止录制。

## 1 连接 Jetson 并确认设备就绪

### 第一步 连接采集热点

给 Jetson 和三台相机供电，确认三台相机已通过 USB 接入 Jetson。佩戴时核对左右腕：A 为右腕，B 为左腕。

在手机 Wi-Fi 设置中连接 **Jetson 提供的热点**。热点名称和密码以设备标签或现场配置为准。手机若提示“无法上网”，选择保持连接。

### 第二步 打开采集页面

在手机浏览器地址栏输入：

`http://10.77.0.1`

如果首页打不开，保持连接同一个热点，再输入：

`http://10.77.0.1:8765/mobile`

打开后，底部应有 **采集、记录、设备** 三个页面。采集用于起停录制，记录用于查已保存的录次，设备用于查连接和时间状态。

### 第三步 检查三台相机

进入 **设备** 页，分别查看头部、左腕和右腕。设备可能依次显示“等待 USB”“正在校时”“等待图像”“等待 VIO”，最终应显示 **已就绪**。VIO 是相机根据图像和惯性数据计算的位置与运动。

返回 **采集** 页，起录前检查三路画面与实际佩戴方向是否相符。点击单路画面可以放大。

同时在设备页的 **存储** 卡片核对保存路径和可用空间。出现备用存储或采集盘异常提醒时，先让负责人员确认保存位置，再继续。

**本步完成标志：页面已连接，三台设备都已就绪。** 下一步选择任务。设备未就绪时，按第 5 节排查。

## 2 选择任务并完成一条录制

**任务**用于归类同一种采集动作；**Take** 是这个任务下的一次录制。例如“拿起杯子并放回”是一个任务，做三次就有三条 Take。

### 第一步 选择或创建任务

在 **采集** 页底部点击 **选择任务**；已有任务时按钮显示 **切换**。

- 使用已有任务：在列表中选中任务，再点击弹窗内的 **切换**。
- 创建新任务：点击 **新建任务**，填写 **任务名称** 和 **任务说明**，再点击 **创建任务**。

关闭弹窗后，核对底部显示的任务名称和“下一条 Take”编号。只在下拉列表选中名称，还没有完成任务切换。

### 第二步 开始录制

页面显示 **可以开始录制** 后，点击 **开始录制**。先等待“正在准备”结束，看到 **正在录制** 和计时，再执行采集动作。

如果需要头部与双腕处于同一张地图中的轨迹，按第 3 节完成校准后再做正式动作。也可以先开始录制，再校准，把校准过程一并保存。

**准备、录制和保存期间，手机预览会暂停。** 这是正常行为；判断是否在录制，要看状态和计时。保存完成后，回到前台的采集画面，预览会恢复。

### 第三步 结束并保存

动作完成后，点击 **结束并保存**。页面显示“正在保存”时，保持设备供电，不拔采集盘，不重复起录。

看到 **Take 编号 + 保存完成** 后，点击 **查看记录**，核对本条是否属于正确任务。保存完成才可以开始下一条。

**本条完成标志：任务正确、Take 正确，页面明确显示保存完成。** 文件能否回放、数据是否完整，还需在 Qt 中复查。

## 3 需要公共轨迹时进行校准

三台设备各自能输出运动数据，不代表它们已经使用同一个坐标系。校准让头部建立公共地图，再让左右腕定位到这张地图中，便于查看三者的相对运动。

只保存原始数据时，系统允许地图定位尚未完成就开始录制。需要公共轨迹时，把下列步骤作为正式动作前的准备。

### 按这个顺序操作

1. **选择场景。** 头部和双腕都能观察到同一片有纹理、光照稳定的环境。避开大面积纯色、强反光和重复图案。
2. **重建地图。** 在采集页找到 **校准与定位** 卡片，点击 **重新校准**。这会重建当前公共地图。
3. **让头部建图。** 缓慢移动头部视角，观察周围环境，等待地图形成。
4. **让双腕定位。** 左右腕分别缓慢观察头部已经看到的环境，等待三台设备显示 **已定位**。
5. **做一次短动作。** 切到 **轨迹**，缓慢移动头部和双腕，检查相对运动是否合理，再进入正式动作。

如果从录制开始后才校准，记下校准完成时刻，后续复查时将校准过程与正式动作分开。

### 如何判断当前状态

| 显示 | 下一步 |
| --- | --- |
| 已定位 | 检查相对运动，确认后执行动作 |
| 等待定位 | 让该设备重新观察已建图的场景，缓慢改变视角 |
| 仅本地 VIO | 仍有本机运动估计，但不能当作已完成公共地图定位 |
| 离线 | 转到设备页，检查供电、USB、图像、时间和 VIO |

相机重启、VIO 重置、更换设备、佩戴位置改变或长时间断流后，重新确认校准。**重新校准只重建公共地图，不能修复相机内部标定缺失。** 回放、起录准备和保存期间不能重建地图。

## 4 查看记录并结束当天采集

### 找到已经保存的 Take

1. 点击底部 **记录**。
2. 打开对应任务，再打开要查看的 **Take**。
3. 核对编号、时长、保存状态以及质量检查和异常信息。

浏览历史任务不会切换当前采集任务。返回采集页后，仍要核对底部的当前任务名称。

手机记录页适合核对“这条有没有保存、属于哪个任务”。查看视频与轨迹回放、检查原始话题完整性、运行轨迹评分，使用《电脑 Qt 使用指南》中的操作。

### 区分结束任务与删除数据

**结束当前任务**：在采集页打开任务弹窗后操作。它结束本次任务使用，历史录次仍然保留。

**删除任务或 Take**：在记录页相应入口操作，并核对确认弹窗。删除涉及原始数据，应先完成备份。录错或动作不合格时，交由复查人员在 Qt 中作废并保留原因，不用删除来代替质量判断。

### 收工前确认三件事

1. **录制已停止。** 最后一条明确显示保存完成；手机退出页面不能代替停止。
2. **记录已核对。** 记下本批任务、Take 范围，以及失败或需复查的录次。
3. **数据已交接。** 让负责人员从 Jetson 备份整条录制目录和任务记录，核对副本后再按现场流程关机。

数据保存在 Jetson 的采集目录中，不会因为手机显示“保存完成”就自动复制到手机。不要在保存过程中关机或拔盘。

## 5 遇到问题时怎么处理

| 现象 | 处理方法 |
| --- | --- |
| 页面打不开 | 回到 Wi-Fi 设置，确认仍连接 Jetson 热点；保持连接后再试首页和备用地址 |
| 页面可开，但设备未就绪 | 进入设备页，按头部、左腕、右腕逐个看停在哪个阶段，检查对应供电和 USB |
| 时间一直未就绪 | 确认手机日期时间正确；设备空闲时在设备页点击“重新校时”。仍失败则保存诊断 |
| 开始录制按钮不可用 | 核对任务是否已切换成功，再点“查看状态”阅读阻止起录的原因；若 Qt 正在回放，先让其返回 Live |
| 正在录制，但手机没有画面 | 录制期间会暂停预览；看录制状态和计时，保存完成后再看画面 |
| 手机断网、锁屏或关闭页面 | 重新连接热点并打开页面，先确认当前 Take 和实际状态；若仍在录制，点击“结束并保存” |
| 保存不结束 / 操作失败 | 保持供电和原始数据，记下错误与 Take；保存诊断并交维护人员处理，避免反复起录或重启 |
| 双腕有图像但无法定位 | 按第 3 节让双腕观察共同场景；持续异常时检查 VIO 状态并保存诊断 |

### 把问题交给维护人员

在 **设备 → 诊断** 中点击 **保存诊断**，同时记录发生时间、任务、Take、错误原文以及刚才做过的操作。

界面语言可在 **设备 → 语言** 中切换简体中文或 English。

手机和 Qt 共用后端。一端正在录制、保存或回放时，另一端会受到相应限制。如果状态和预期不一致，先核对另一端正在做什么。
