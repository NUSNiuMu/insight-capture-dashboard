# 离线语音控制

在 Jetson 宿主机使用 `scripts/run_voice.sh`，通过本地语音识别、固定命令和后端 API 控制采集。无需公网或助手服务。状态在 Qt 和手机同步，启动服务前需要配置可用的音频设备和语音模型。

支持“开始录制”“停止录制”“开始校准”“录制校准模式”“系统状态”“当前任务”“结束当前任务”“本条作废”，以及配置中的叠杯任务命令。录制期间可重新校准普通采集；保存期间等待完成。语音只停止由语音接口创建的录制，手动录制应由 Qt 或手机停止。

唤醒词为“宸境”，唤醒反馈后说命令。未识别命令只提示重新说出采集指令，不执行外部助手。固定检测位检查及相关语音命令已移除。音量与试听可在 Qt 设置页调整。

`deploy/install_voice_control_service.sh` 安装离线语音服务；未启动语音服务时不影响 Qt/手机采集。模型和麦克风准备完成后再启动。运行状态可用 `systemctl --user status insight-voice-control.service` 查询。
