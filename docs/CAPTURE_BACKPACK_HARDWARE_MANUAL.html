04 / 电池与供电线束

两条独立供电路径

主机：电池 D-Tap → 配套 D-Tap 转 DC 线 → Jetson DC。

相机：电池 12V → 一分三供电线 → 三台相机各自的 8-pin 电源连接。

本方案不依靠 Jetson 的 USB 口承担相机工作电源。USB 插好但没有 12V 供电，相机仍不能按本方案正常工作。

原照片中可见其他 USB-C、USB-A 电源口标识；这些口不是本手册指定的相机供电路径。

安装和更换时必须确认

  • 电池输出关闭后连接 D-Tap、DC 和各相机电源接头；接头方向正确、插接到位。
  • 使用已配套验证的线束。安装手册未给出 8-pin 针脚、电源极性、线径及各输出电流上限，不可仅凭外形自行改线。
  • 一分三的三条支路分别供给三台相机；整理线束并固定受力点，避免接口承受背包运动产生的拉力。
  • 电池到 Jetson 的路径和相机 12V 路径不同，不能把“相机 12V”当成 Jetson 的额定输入规格。
电量与续航：本机有 INA3221 电压／电流监测，但未注册电池／UPS 电量设备。上一轮盘点的 VDD_IN≈14.68V 只是主机监测点的瞬时读数，不能据此推算电池容量、剩余电量、允许输入范围或续航。

待补：电池型号、Wh／Ah、D-Tap 电压范围、12V 电流上限、充电要求、线束额定值及稳压方式。照片中的单个功率标识不能替代上述规格。

数值依据与使用范围

基线由实时 /tf_static 中各设备 camera_left → camera_right 的平移向量长度计算，并用左右 CameraInfo 投影矩阵交叉核对：B = |P右[3]/P右[0] − P左[3]/P左[0]|（米）。三台设备两种结果之差均小于 0.00001 mm。

08 / 安装与线缆固定

  1. 关闭电池输出。确认 Jetson 和三台相机均未通电，检查插头无弯针、破损和松动。
  2. 固定设备。按右手 A、左手 B、头部 A 对应相机角色；保留镜头视野和主机散热通道。
  3. 连接主机电源。D-Tap 端接电池，DC 圆口接主机标有 DC 的输入口。
  4. 连接相机电源。12V 一分三线接电池 12V 口，三路 8-pin 分别接三台相机；确认方向，勿倾斜硬插。
  5. 连接数据。三根 USB 线分别连接相机数据口和主机 USB 口。不要把只供电的线当作数据线。
  6. 整理与标记。建议在线缆两端标注 A-右手、B-左手、9-头部；固定线束，预留活动余量，避免拉扯、夹压及过度弯折。
接线完成再通电。所有电源接头均应在对应供电关闭后装拆，尤其不要带电反复插拔相机侧 8-pin。正常停机须先停止录制并完成系统关机。

09 / 启停顺序

日常上电

  1. 断电完成第 10 页接线检查，先确保三条相机 USB 数据线已经插好。
  2. 若电池支持主机与相机分路控制：先给 Jetson 上电，待主机启动完成后再使能相机 12V 输出。相机侧 8-pin 保持插接。
  3. 若只能总开关同时上电：全部接头在断电时接好，再按配套安装流程打开总输出；等待主机启动，并核实系统是否完成相机恢复和实际出图。不要假定任何机器都能自动恢复。
  4. 进入采集界面，确认右手、左手、头部三路画面持续更新，检查所需位姿、录制目录和可用空间，再进行采集。

原安装手册采用整体通电流程；项目后续前端手册补充了“USB 先接、Jetson 就绪后给相机 12V”的现场经验。本页按实际分路控制能力区分；电池是否支持独立开关尚未确认，不能要求带电改接 8-pin 来实现顺序。

正常关机

  1. 先停止当前录制，等待界面确认结束、文件写入和停止处理完成。
  2. 在 Jetson 系统中执行正常关机，等待系统完全停止。
  3. 关闭电池输出。确认设备断电后再拆卸 USB、电源线或外置录制盘。

USB 松脱或重插后没有恢复

先接稳 USB，再检查画面是否持续更新。仅重插 USB 可能不足以恢复相机发现；需要重新给相机上电时，先结束录制并关闭相机供电支路，再恢复该支路。若无法独立控制相机电源，按完整关机流程断电后重启。

共同影响：三台相机共用 12V 一分三线和 USB Hub 上行。关闭共同电源或断开共同上行，会影响多路相机；不要在录制中为排查一路相机而直接切断共同电源。

启动检查清单

  • 主机与三台相机均独立接好指定供电线路。
  • 三路画面持续更新，角色与实际佩戴位置一致。
  • 录制目标盘、空间及 fallback 提示已核对。
  • 线缆没有拉扯接口，散热通道与镜头无遮挡。

10 / 常见问题与只读检查

现象优先检查
Jetson 无法开机电池输出、D-Tap、DC 输入口及接头固定。不要把相机的 12V 路径当成主机输入规格。
某台相机无数据同时检查该路 12V 支路和 USB；再看是否有对应 cdc_ncm 网卡、相机管理响应以及实际图像／VIO。
三路同时消失先查共用相机供电、一分三线、Hub 与上行路径。仅凭同时掉线不能认定电池电压异常。
相机 IP 可访问但无画面管理服务与 ROS 数据不是同一验收项；继续看实际消息和页面更新，不要先改 DDS 域号。
录制没有落到 USB 盘查实际挂载源与 using_fallback，确认外置盘是否存在并可写。不要在录制期间切换存储。
语音无输入或无播报先确认 USB 音频硬件已枚举，再查语音服务；只有板载 HDA／APE 不代表外置麦克风和音响在线。
电源接头异常发热／有焦味停止使用并按现场条件安全断电，检查线缆和接头；不要反复试插继续运行。
